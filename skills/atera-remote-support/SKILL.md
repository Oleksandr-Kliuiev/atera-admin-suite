# Atera Remote Support

Use the existing authenticated **Chrome** session and read the [shared browser contract](../atera-organization-lifecycle/references/browser-operation-contract.md) once per working context.

Read [remote support operations](references/remote-support.md). Resolve exact device and related ticket, and verify consent or approved unattended-support basis. Start read-only; use configured providers/authentication without requesting or storing remote credentials.

Remote-session launch is a critical privacy commit. Limit content access and elevated commands to the support task. Service/registry changes, termination, logout, reboot, shutdown, and destructive controls need the exact effect summary and existing or missing authorization. Preserve the user's work.

Report device/ticket IDs, consent/authentication state, observations, commands/changes, before/after evidence, user impact, session closure, unresolved risks, and follow-up; omit unnecessary sensitive content.
