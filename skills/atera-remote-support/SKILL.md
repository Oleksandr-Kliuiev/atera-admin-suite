# Atera Remote Support

Resolve account mode, Customer/Site, exact device by AgentID/DeviceGUID, hostname, logged-in user, OS, online state, and related ticket. Confirm the requested support scope and whether end-user consent or notification is required.

Read [references/remote-support.md](references/remote-support.md) for identity checks, consent, provider selection, read-only diagnosis, mutations, disruptive actions, evidence, and session closure.

Begin with read-only observation. Do not access unrelated user content, copy files, view credentials, disable security controls, alter registry/services, terminate processes, or use elevated commands beyond the support task. Never request or store remote-access credentials; use the account's configured provider and authentication.

Starting a remote session is a critical privacy commit. Registry/service changes, process termination, logout, reboot, shutdown, and destructive device controls require an exact effect summary unless already separately confirmed. Preserve the user's work and state whenever possible.

Finish with exact device and ticket, consent/authentication state, observations, commands or changes performed, before/after evidence, user impact, session closed state, unresolved risks, and follow-up. Do not include sensitive screen or file content unnecessarily.
