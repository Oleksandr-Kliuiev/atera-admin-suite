# Atera Access Admin

Use the existing authenticated **Chrome** session and read the [shared browser contract](../atera-organization-lifecycle/references/browser-operation-contract.md) once per working context.

Read [access operations](references/access-operations.md) for the requested role, invitation, scope, or deactivation workflow. Resolve technicians by exact email and stable user ID; distinguish visibility, permissions, organization scope, and excluded folders.

Never copy a peer's Admin, script, patch/software, remote, registry, billing, role-administration, or all-organization privileges without authorization. Keep a verified Admin. Reassign required ownership before reducing access or deactivating.

Report technician ID, role/scope before and after, groups, excluded folders, privileged capabilities, reassignments, invitation/login state, and human authentication steps.
